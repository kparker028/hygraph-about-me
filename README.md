# Hygraph Portfolio

A Next.js portfolio that reads published content from Hygraph. It includes an about page and a project index with individual project detail pages.

## Requirements

- Node.js 22.15.0, defined in `.nvmrc`
- npm 10.9.2 or later

This repository uses npm and `package-lock.json`. Do not use Yarn for installs.

## Local Development

```bash
nvm use
npm ci
```

Create a local `.env` file with your Hygraph Content API endpoint:

```bash
HYGRAPH_API_URL=https://api-us-west-2.hygraph.com/v2/<project-id>/<environment>
```

Keep environment files local. Do not add API credentials or secrets to Git.

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000.

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Next.js development server. |
| `npm run build` | Create a production build. |
| `npm run start` | Serve an existing production build. |
| `npm run lint` | Run ESLint. |
| `npm run typecheck` | Run TypeScript without emitting files. |
| `npm run generate` | Generate GraphQL documents and types from the Hygraph schema. |
| `npm run check` | Run linting, type checking, and a production build. |

Run `npm run generate` after changing a file in `src/features/**/*.graphql` or after changing the Hygraph schema. It is separate from `npm run check` because it requests the remote schema.

## Routes

| Route | Purpose |
| --- | --- |
| `/` | Portfolio landing page. |
| `/about` | About content from Hygraph. |
| `/projects` | Project index from Hygraph. |
| `/projects/[slug]` | Individual project detail page. |

## Architecture

- `src/app/` contains App Router routes, loading states, and route-level error boundaries.
- `src/features/` owns feature GraphQL operations, server fetchers, and feature-specific presentation code.
- `src/features/**/*.graphql` contains the authored GraphQL operations.
- `src/graphql/generated/` is generated by GraphQL Code Generator. Do not edit it directly.
- `src/lib/hygraph/server-client.ts` is the server-only Hygraph client. Client Components must not import it.
- `src/react-query/` contains the future TanStack Query scaffold. Current Hygraph reads remain server-rendered because the portfolio has no client-side data interactions.

Hygraph data is cached for one hour. About and project-list pages use ISR; project detail pages render on demand and cache each project read for the same period.

## Deployment

Set `HYGRAPH_API_URL` in the deployment environment. Build with:

```bash
npm ci
npm run generate
npm run check
```
